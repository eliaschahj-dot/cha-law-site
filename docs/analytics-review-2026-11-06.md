## 2. 사람들은 어떻게 들어와서 어디서 나가는가

**네이버 검색 → 홈 → 소개 → 이탈.** 네이버에서 홈으로 들어온 8세션은 대부분 `/inheritance-lawyer`(변호사 소개)를 보고 나갔다(소개 페이지 이탈률 71%, 종료 페이지 2위). "이 변호사가 누구인지"를 확인한 다음 상담으로 이어질 고리가 없다.

**네이버 검색 → 부동산 안내 페이지: 가장 뜨거운 방문.** `/real-estate/guide/eviction` 371초 → 강제집행 비용 칼럼 821초 → 다시 안내 137초(합계 22분), `presale-cancel` 552초, `gagyeyak` 137초, `defects` 82초를 11분 간격으로 두 번. 문제를 안고 온 사람들인데 상담 신청은 없었다.

**부동산 상담 페이지를 4번 들어오고 신청 안 함(10/31 12:45, 네이버앱 모바일, 267초).** `/real-estate/contact` 58초 → 23초 → 홈 → 보증금 분야 → 상담 33초 → 83초. Render 로그 7일치에 메일 발송 실패는 없으므로 전송 오류는 아니다. 폼이 길거나(입력칸 12개), 전화번호를 찾다가 포기했거나, 자동완성이 허니팟(`company` 칸)을 채워 조용히 버려졌을 가능성이 남는다.

**구글 검색 → 꿀팁 칼럼 → 이탈.** 구글 유입 13세션 중 8세션이 '융자 있는 집 월세', '월세 복비 계산', '월세 가계약금', '전입신고 확정일자' 같은 세입자 정보글로 들어와 30~150초 읽고 나갔다. 변호사 선임 의도가 낮은 독자이고, 글 안에 부동산 분쟁 안내로 넘어갈 연결이 없다.

**카카오톡 공유 → 홈 5~54초 → 이탈.** 10/27 22:41~22:44 7세션처럼 지인에게 공유된 링크는 홈 첫 화면만 보고 닫힌다. 홈이 8개 섹션으로 길어 모바일 첫 화면에서 '누구·무엇·얼마·어떻게 연락'이 한눈에 안 들어온다.

**chatgpt.com 추천 3세션**은 바로 소개·비용 페이지로 왔다. AI 검색이 이미 이 사이트를 인용하기 시작했고, 비용·FAQ·구조화 데이터가 잘 돼 있는 페이지가 뽑힌다.

**모바일에서 홈 ↔ 칼럼을 11번 오간 세션(11/03 00:29).** `/columns/Inheritance-Lawyer-Hiring`에 들어갔다가 홈으로 되돌아오기를 5회 반복. 모바일 칼럼 페이지에서 뒤로가기나 상단 링크가 홈으로 튀는 문제가 있는지 점검이 필요하다.

## 4. 측정 자체의 미비점

1. 봇이 걸러지지 않는다. UA 정규식만으로는 일반 브라우저 UA를 쓰는 해외 크롤러를 못 잡는다. 체류 이벤트 없이 끝난 해외 세션을 '봇 추정'으로 분리하고 대시보드 기본값을 '실방문'으로 두어야 한다.
2. 스크롤 깊이가 전 페이지 100%로 기록된다. 측정 함수가 본문이 그려지기 전에 먼저 실행돼 '문서 높이 ≤ 화면 높이 → 100'으로 잡힌다. load 이후에 측정을 시작해야 한다.
3. 전화·카카오톡 버튼 클릭이 기록되지 않는다. 모바일 방문자는 폼보다 전화를 쓰므로, 지금의 "상담 0건"이 실제 0건인지 알 수 없다.
4. 허니팟에 걸린 제출은 조용히 성공 처리된다. 허니팟 적중도 로그로 남겨야 10/31 같은 사례를 가릴 수 있다.
5. 카카오톡·블로그·명함 링크에 UTM이 없어 공유 효과를 분리해 볼 수 없다.

## 5. 보완 과제(우선순위)

**A. 전환 경로(가장 급함)**
1. 부동산 안내·상황 페이지 본문 중간(두 번째 소제목 뒤)에 "이 상황이면 지금 상담" 상자: 전화 버튼 + 3칸 간이 신청(이름·연락처·한 줄). 22분 읽는 사람을 그 자리에서 잡는다.
2. 상담 폼을 2단으로: 필수 3칸만 먼저 보이고, 사망일·상속인·분쟁 유형 등은 "더 자세히(선택)"로 접기. 전화번호를 폼 위에 크게.
3. 소개 페이지(`/inheritance-lawyer`, `/real-estate/lawyer`) 하단에 비용 안내 링크 + 상담 흐름 3단계 + 상담 버튼. 지금은 읽고 나갈 곳이 없다.
4. 홈 첫 화면(모바일)에 한 줄 요약: 분야 2개·부대표·삼성역·전화. 카카오톡으로 공유받은 사람이 10초 안에 판단하게.
5. 전화·카카오톡 클릭 이벤트 기록, 허니팟 적중 로그.

**B. 검색 유입의 질**
1. 꿀팁 칼럼마다 글 끝과 중간에 "이 문제로 분쟁이 생겼다면" 상자로 부동산 하위 사이트 안내 페이지(가계약금·하자·명도·보증금)에 연결. 세입자 독자를 미래 의뢰인으로 바꾸는 유일한 통로.
2. 노출 많고 클릭 없는 글(융자금 있는 집 월세, 유서 쓰는 법, 전세 안고 매매, 셀프 상속포기)의 메타 제목·설명을 질문형·숫자형으로 다시 쓰기. 재작성 글의 주소가 바뀐 뒤 2주 지나 서치 콘솔에서 재확인.
3. 핵심 키워드는 외부 신호 없이는 안 오른다: 변협 전문분야 등록(상속·부동산), 네이버 플레이스·구글 비즈니스 프로필에 홈페이지 주소 등록, 네이버 블로그 프로필·각 글 하단에 `?utm_source=naverblog` 링크, 기고·강의 소개 페이지에서 역링크.
4. '내용증명 주소 모를 때'는 유일하게 클릭이 나는 글이다. 같은 결의 절차형 글(공시송달·보정명령·송달 불능)을 2~3편 더 써서 묶는다.

**C. 측정**
1. 봇 추정 분리 + '실방문' 기본 보기, 스크롤 깊이 수정, 전환 이벤트 추가(위 A-5).
2. 네이버 서치어드바이저 유입 검색어를 월 1회 수동 확인해 이 문서에 추가.
3. 한 달 뒤(12월 초) 같은 기준으로 다시 비교: 실방문 세션, 검색 유입 수, 안내 페이지 → 상담 페이지 이동률, 전화 클릭 수.
