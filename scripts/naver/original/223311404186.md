이 글은 **변호사가 직접 정리한 전세사기 예방법: 부동산도 안 알려주는 진짜 집주인 확인 방법**입니다.

제가 부동산 전문 변호사로 일할 때 만났던, 집주인이 아닌 사람과 계약했다가 전 재산이나 다름없는 보증금을 잃고 망연자실했던 분들이 떠오릅니다.

지금부터 이 글을 3분만 집중해서 읽으시면 전세사기 예방법을 숙지하실 수 있고, 앞으로 여러분과 전세 계약을 맺으려는 사람이 진짜 집주인인지 바로 확인하실 수 있습니다.

아래 목차를 확인하시고 여러분에게 필요한 정보를 빠르게 얻어 가세요!

> 전세사기 예방법: 진짜 집주인 확인 방법
> 1. 신분증 진위 여부 확인하는 법
> ① 주민등록증
> ② 운전면허증
> 2. 본인 확인 서류 진위 여부 확인하는 법
> ① 인감증명서
> ② 본인서명사실확인서
> 3. 사기꾼 꼼짝 못 하게 만드는 꿀팁😎

## 1. 신분증 진위 여부 확인하는 법

![전세사기 예방법, 부동산도 안 알려주는 진짜 집주인 확인 방법 - 이미지 2](/columns/223311404186/02.webp)

![전세사기 예방법, 부동산도 안 알려주는 진짜 집주인 확인 방법 - 이미지 3](/columns/223311404186/03.webp)

임대차 계약을 맺을 때, 임대인(또는 대리인)의 신분증을 확인하는 것은 전세사기 예방법의 기본입니다. '공인중개사가 알아서 잘 챙겨주겠지'라고 생각하며 안심하지 마시고, 여러분이 직접 확인해 주세요.

### ① 주민등록증 진위 여부 확인하는 법 (총 2가지)

**★ 준비물: 진위를 확인하려는 주민등록증 상의 이름, 주민등록번호, 발급일자**

![전세사기 예방법, 부동산도 안 알려주는 진짜 집주인 확인 방법 - 이미지 4](/columns/223311404186/04.webp)

- **ARS 전화 국번없이 1382**

![전세사기 예방법, 부동산도 안 알려주는 진짜 집주인 확인 방법 - 이미지 5](/columns/223311404186/05.webp)

국번없이 '1382'를 누르고 ARS 안내 멘트에 따라 주민등록번호와 발급일자를 눌러주세요.

- **정부24 홈페이지 (또는 휴대폰 어플)**

(1) 정부24 로그인 (공동인증서 또는 간편인증)

(2) 민원서비스 → '사실/진위 확인' 클릭

![전세사기 예방법, 부동산도 안 알려주는 진짜 집주인 확인 방법 - 이미지 6](/columns/223311404186/18.webp)

(3) '주민등록증 진위확인/잠김해제' 클릭

![전세사기 예방법, 부동산도 안 알려주는 진짜 집주인 확인 방법 - 이미지 7](/columns/223311404186/07.webp)

(4) '주민등록증 진위확인' 버튼 클릭

![전세사기 예방법, 부동산도 안 알려주는 진짜 집주인 확인 방법 - 이미지 8](/columns/223311404186/08.webp)

(5) 주민등록증 상의 이름, 주민등록번호, 주민등록 발급일자를 입력하고, 화면에 보이는 숫자를 입력확인 칸에 입력한 후 확인 버튼을 누릅니다

(6) **만약 "일치는 하지만 분실신고된 증입니다" 또는 "일치하지 않습니다"라는 문구가 나타나면 해당 주민등록증을 제시한 사람과는 계약하지 마세요**

### ② 운전면허증 진위 여부 확인하는 법 (총 1가지)

**★ 준비물: 진위를 확인하려는 운전면허증 상의 생년월일, 이름, 면허번호, 식별번호**(면허증 앞면 우측 작은 사진 밑 6자리)

![전세사기 예방법, 부동산도 안 알려주는 진짜 집주인 확인 방법 - 이미지 9](/columns/223311404186/09.webp)

- **경찰청 교통민원24 홈페이지 (또는 휴대폰 어플)**

(1) 경찰청 교통민원24 로그인 (공동인증서 또는 간편인증)

(2) 조회 → 운전면허 → '운전면허증 진위여부' 클릭

![전세사기 예방법, 부동산도 안 알려주는 진짜 집주인 확인 방법 - 이미지 10](/columns/223311404186/10.webp)

(3) 운전면허증 상의 생년월일, 성명, 면허번호, 식별번호를 입력합니다

(4) "전산 자료와 일치합니다. 식별 번호가 일치합니다"라는 문구가 나타나면 안심하셔도 됩니다.

## 2. 본인 확인 서류 진위 여부 확인하는 법

부동산 거래할 때 임대인의 신원을 확인하기 위해서 꼭 필요한 서류 중 하나가 바로 '인감증명서'입니다. 최근에는 인감증명서와 효력이 같은 '본인서명사실확인서'로도 대체하는 추세인데요.

**두 서류 중 어느 것을 받으시든지 '발급 3개월 이내'의 것이어야 하며, 진위 여부 역시 꼭 확인하셔야 합니다.**

### ① 인감증명서 진위 여부 확인하는 법 (총 1가지)

**★ 준비물: 진위를 확인하려는 인감증명서 상의 발급일자, 주민등록번호, 확인용 발급번호**

(2) 민원서비스 → '사실/진위 확인' 클릭

![전세사기 예방법, 부동산도 안 알려주는 진짜 집주인 확인 방법 - 이미지 14](/columns/223311404186/18.webp)

(3) '인감증명발급 사실확인' 클릭
