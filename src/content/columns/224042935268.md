안녕하세요. 차형진 대표 변호사입니다.

오늘 글은 저희 사무실 홍보를 위한 글도 아닙니다.

상속 관련 여러 성공사례들이 있지만 그런 것보다도 셀프 상속포기 방법에 대한 내용을 순차적으로 알려드리는 것이 훨씬 이해가 되실 거라 생각됩니다.

아래 5가지를 읽어보시는 것만으로도 셀프 상속포기 방법에 대한 모든 것을 알아가실 수 있을 겁니다.

그럼 바로 시작하겠습니다.

(글을 읽고도 헷갈리는 부분이 있다면 아래 링크를 통해 문의 남겨보세요. 사무장이 아닌 제가 연락드립니다.)

## 1. 상속 포기, 가장 중요한 '기간'을 놓치지 마세요!

상속 포기는 망인(피상속인)이 사망한 날로부터 3개월 이내에 신청해야 합니다. 이 기간을 놓치면 상속을 '승인'한 것으로 간주되어 망인의 빚까지 떠안게 될 수 있으니, 기간 준수가 무엇보다 중요합니다.

신청은 망인의 주민등록상 최후 주소지를 관할하는 가정법원에 해야 합니다.

## 2. 필수 서류 완벽하게 준비하기

상속 포기를 신청할 때 필요한 서류는 크게 망인(돌아가신 분) 서류와 상속 포기자(신청인) 서류로 나뉩니다.

### 서류 발급 시 유의사항

모든 기본 서류는 주민등록번호 뒷자리까지 모두 나오도록 '상세'로 발급받아야 합니다. 정부 24 홈페이지나 가까운 주민센터에서 발급받을 수 있습니다.

| 구분 | 서류 종류 | 발급 대상 | 비고 |
|---|---|---|---|
| 망인의 서류 | 기본 증명서(상세) | 망인 |  |
| 가족관계증명서(상세) | 망인 |  |  |
| 주민등록등본(최후 주소지 포함) | 망인 | 말소자 등본 |  |
| 주민등록초본(주소 변동 내역 포함) | 망인 |  |  |
| 상속 포기자의 서류 | 기본 증명서(상세) | 상속 포기자 | 성인도 준비 권장 |
| 가족관계증명서(상세) | 상속 포기자 |  |  |
| 주민등록등본 | 상속 포기자 |  |  |
| 인감증명서 | 상속 포기자 | 본인 서명사실 확인서로 대체 가능 |  |
| 인감도장 | 상속 포기자 | 서명으로 대체 가능 |  |
| 추가 서류 | 법정대리인(친권자) 서류 | 미성년자 상속 포기 시 | 기본 증명서, 인감증명서, 인감도장 등 |
| 가계도 | 가족관계가 복잡할 경우 | 후순위 상속인까지 포함해 청구할 때 |  |

중요 안내: 상속 포기는 1순위 상속인이 포기하면 그다음 순위(2순위, 3순위 등)로 빚이 승계됩니다. 4촌 이내 반계 혈족까지 빚이 넘어가지 않도록,

1순위와 후순위 상속인이 함께 혹은 순서대로 포기 신청을 하는 것이 가장 안전합니다. 후순위 상속인도 1순위 상속인과 동시에 신청할 수 있습니다.

## 3. '상속 포기 심판 청구서' 작성 방법

서류가 준비되었다면, 법원에 제출할 핵심 서류인 상속 포기 심판 청구서를 작성할 차례입니다. 인터넷에서 양식을 다운로드하여 아래 순서대로 빈칸을 채우세요.

### ① 청구인(상속 포기자) 정보 기재

- 성인: 이름, 주민등록번호, 주소, 등록기준지(본적)를 기재합니다.
- 미성년자: 위 내용에 더해 "청구인 〇〇〇은(는) 미성년자이므로" 문구를 추가하고, 법정대리인(친권자 부/모)의 성명을 함께 기재해야 합니다.

### ② 사건본인(망인) 정보 기재

- 망인의 이름, 주민등록번호, 사망 일자, 등록기준지, 최후 주소 순으로 기재합니다.
- 주의: 기본 증명서에 표기된 사망 일시(날짜)를 기재해야 하며, 사망신고 일자가 아닙니다.

### ③ 청구취지 작성 (핵심 문구)

이 부분이 가장 중요합니다. 아래 문구를 그대로 적으시면 됩니다.

> "청구인들은 피상속인 망 〇〇〇(망인의 성함과 주민번호)의 재산 상속을 포기하는 신고를 수리한다는 심판을 구합니다."

### ④ 청구원인 작성

청구취지를 뒷받침하는 이유를 간결하게 2가지로 작성합니다.

1. 망인의 사망 사실 및 관계: 망인과 청구인(상속인)과의 관계, 망인의 사망 사실을 기재합니다.
2. 포기 의사: 「민법 제1019조」에 따라 망인의 재산 상속을 포기하고자 하니 이를 받아달라는 내용을 기재합니다.

### ⑤ 소명 방법 및 첨부 서류

앞서 준비한 서류 목록을 그대로 기재합니다. (예: 가족관계증명서, 기본 증명서, 인감증명서 등)

### ⑥ 마무리

작성 날짜, 신청인 이름(서명 또는 날인)을 기재하고, 맨 하단에 "〇〇가정 법원 귀중" (관할법원 이름)을 기재하여 작성을 완료합니다.

## 4. 법원에 심판 청구서 제출하기 (2가지 방법)

작성된 청구서와 준비된 서류를 법원에 제출할 차례입니다. 신청 시에는 인지대와 송달료라는 별도의 소송 비용을 납부해야 합니다.

### 셀프 상속포기 방법 1: 법원 방문 접수 (가장 확실한 방법)

장소: 망인의 최후 주소지 관할 가정법원 종합민원실

준비물: 구비 서류 일체, 작성된 심판 청구서

장점: 서류 검토 및 비용 납부가 한 번에 처리되어 실수가 적습니다.

### 셀프 상속포기 방법 2: 인터넷 전자소송 접수 (편리한 방법)

사이트: 대한민국 법원 대법원 전자소송 홈페이지

준비물: 신청자 본인 명의의 공동 인증서(구 공인인증서)

장점: 법원에 직접 방문할 필요 없이 24시간 언제든 접수가 가능합니다. (단, 서류 스캔 및 온라인 작업이 익숙해야 합니다.)

## 5. 사건 진행 상황 실시간 확인 방법

신청서를 법원에 접수하면 해당 신청 건에 대한 사건 번호가 부여됩니다.

사건 진행 상황은 대법원 나의 사건 검색 홈페이지에서 사건 번호를 입력하여 실시간으로 확인하실 수 있습니다.

접수 후 법원에서 '보정명령'이 나올 수도 있습니다. 이는 서류가 미비하거나 빠진 내용이 있을 때 법원에서 서류를 보충하라고 요구하는 것이니, 당황하지 마시고 보정명령 내용을 참고하여 신속하게 서류를 준비해 다시 제출하시면 됩니다.

오늘 알려드린 셀프 상속포기 방법대로 서류 준비와 신청서 작성, 법원 제출까지 꼼꼼하게 진행하셔서 상속 포기를 성공적으로 완료하시길 바랍니다.
